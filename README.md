# DOT Viagens

Pesquisa de voos em reais com selecção de ida e volta, resumo do itinerário,
catálogo mundial de aeroportos, comparação de datas, filtros e paginação local.

A documentação completa está em **MECANICA_DO_SISTEMA.txt**.

- `pnpm install`
- `pnpm dev`
- `node --test tests/*.test.mjs`
- `pnpm build`

Configure `SERPAPI_KEY` somente no ambiente do Worker. Nunca no frontend.
Pesquisa e comparação não constituem reserva, cobrança ou emissão de bilhetes.
